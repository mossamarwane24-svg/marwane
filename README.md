# marwane

## Codex CLI et terminal tablette

- Documentation complète, état et limites réseau : [docs/codex.md](docs/codex.md)
- Installer ou réinstaller Codex dans le sandbox : `./scripts/install-codex.sh`
- Terminal web pour la tablette : `./tools/webterm/setup.sh` (une fois), puis `python3 tools/webterm/server.py`. Aperçu « Terminal tablette » sur le port 8420, protégé par mot de passe.
