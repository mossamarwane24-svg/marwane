# Démo du menu de la vidéo

Cette petite application Node.js reproduit uniquement la partie de démonstration visible à la fin de la vidéo : un menu avec les options « Hello World », « Abonnez-vous », « Likez ou commentez » et une option qui affiche les trois messages.

## Lancer le projet

Prérequis : Node.js 18 ou une version plus récente.

```bash
npm start
```

Choix disponibles :

- `1` — afficher « Hello World » ;
- `2` — afficher le message d'abonnement ;
- `3` — afficher le message de like/commentaire ;
- `4` — afficher les trois messages ;
- `0` — quitter.

## À propos du lien partagé

La vidéo présente aussi une méthode pour contourner les quotas de Cursor en supprimant des données d'identification de la machine et en recréant des comptes. Je ne l'ai pas automatisée : contourner une limite de service ou multiplier les comptes peut violer les conditions d'utilisation et entraîner la suspension des comptes.

Pour utiliser Cursor légalement, il vaut mieux rester sur son offre gratuite officielle ou utiliser un abonnement / une clé API autorisée selon les conditions du fournisseur.
